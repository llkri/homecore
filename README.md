## 这个站是怎么来的

最初的构思来自另一个作品：**Hearthly — The smart home that cares**（作者 jikol1906）。

> <https://jikol1906.github.io/Hearthly/>

它做的是「一个温柔到可疑的智能家居品牌，随着滚动慢慢露出真面目」。本站受它启发，
借鉴了**恐惧度驱动的滚动调色引擎**、**sticky 长舞台**、**导航词替换**、
**WebAudio 现场合成氛围音**、**结尾硬切**这套机制。

**没有拿走**：代码、文案、图片——一行都没有。品牌、全部中文文案、画面、结局、
23 个彩蛋、免责声明，都是本站自己的。

喜欢这个形式的话，请先去看原作。
